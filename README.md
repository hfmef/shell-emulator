# Эмулятор языка оболочки ОС

Учебный проект по дисциплине «Конфигурационное управление».
Вариант 7, этап 1.

## Описание

Программа представляет собой графический прототип эмулятора командной
оболочки. Пользователь вводит команду в поле окна, а результат появляется
в области вывода.

Заголовок окна формируется из фактических данных операционной системы:
имени текущего пользователя и имени компьютера.

## Возможности

- графический интерфейс на библиотеке Tkinter;
- разбор введённой строки на команду и аргументы по пробелам;
- команды-заглушки `ls` и `cd`;
- вывод имени команды и её аргументов;
- сообщение об ошибке для неизвестной команды;
- сообщение об ошибке, если у `cd` больше одного аргумента;
- команда `exit` для закрытия приложения;
- выполнение команды по кнопке «Выполнить» или клавише Enter.

## Функции и настройки

- `get_window_title()` формирует заголовок окна;
- `parse_input()` разделяет введённую строку на команду и аргументы;
- `EmulatorWindow` создаёт графическое окно и обрабатывает команды;
- `WINDOW_WIDTH` и `WINDOW_HEIGHT` задают размер окна;
- `PADDING` задаёт отступы элементов интерфейса.
